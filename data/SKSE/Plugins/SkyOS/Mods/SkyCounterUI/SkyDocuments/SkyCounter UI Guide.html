AUTOMATIC PICKUP NOTICE

SkyCounter UI

Show pickup and location notices, and manage the item-icon and location-screenshot caches that SkyCollection displays.

Personalize the notice

Enable or hide

Disable the overlay without turning off collection tracking.

Position

Choose a corner, top or center side, or the center of the screen to avoid other HUD elements. Every design, including the compact Minimal pill, anchors to the selected position using the visible notice's width.

Theme and size

Choose Dwemer cyan, Frost, Imperial gold, or Arcane violet, then set a compact, standard, or large notice.

Details and duration

Control the picked-up count, item category, and plugin name. Choose a notice display time of 500, 1000, 1500, 2000, 2500, or 3000 ms.

Rendering and capture

Control item icon rendering and first-visit location screenshot capture here. SkyCollection reads the item icon cache and displays the images in its catalog.

Requirements

  • Skyrim Special Edition / Anniversary Edition Latest Version (supported runtime).
  • SKSE Latest Version.
  • PrismaUI Latest Version.
  • SkyOS Latest Version.

Integration

SkyCounter UI listens for inventory pickups itself, so notices work without SkyCollection. SkyCollection is an optional integration for save-specific history and location events. SkyCounter UI owns the notice overlay, item-icon renderer, and all rendering controls; SkyCollection only reads the resulting icon cache and displays those images.

Item artwork

SkyCounter UI owns the automatic Skyrim preview renderer and the icon cache in Data/SKSE/Plugins/SkyOS/Mods/SkyCounterUI/Icons/. SkyCollection reads those cached icons for its item catalog. Existing icons remain available when rendering is disabled. SkyCounter UI also listens for map-marker discoveries and captures first-visit screenshots into Data/SKSE/Plugins/SkyOS/Mods/SkyCounterUI/Locations/. SkyCollection only reads this shared cache.

Rendering note. Item artwork is generated in the background by Skyrim's preview renderer. The pickup notice itself does not open inventory or a capture menu.

Rendering and capture controls

Item icons

When Render item icons is enabled, SkyCounter UI requests Skyrim item previews and saves available captures to its icon cache. Turning the option off stops new automatic item-icon rendering; icons already cached remain available to SkyCollection.

Location screenshots

When Capture location screenshots is enabled, SkyCounter UI captures a screenshot for a newly discovered map location and stores it under Data/SKSE/Plugins/SkyOS/Mods/SkyCounterUI/Locations/. Existing screenshots remain available when the option is disabled.

Standalone pickup messages

Pickup detection and notices work without SkyCollection. Hiding Show pickup messages affects the overlay only; SkyCounter UI continues listening for pickups and optional collection integration can keep its save-specific records.

How SkyCollection uses the images

SkyCollection reads the cached icons and location screenshots. It does not own rendering controls and cannot request a new capture. Configure both capture switches in SkyViewer → Modules → SkyCounter UI.

Quick troubleshooting

No new item image

Confirm Render item icons is on, then collect an item whose preview can be loaded by Skyrim. SkyCollection only shows saved cache results; it does not render on page open.

No location image

Confirm Capture location screenshots is on and that the location is a newly discovered map marker. The capture is stored in SkyCounter UI's location cache, outside the save record.

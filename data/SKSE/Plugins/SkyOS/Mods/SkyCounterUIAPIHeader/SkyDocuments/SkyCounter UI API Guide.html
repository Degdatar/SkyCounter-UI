MODDER REFERENCE · C ABI VERSION 1

SkyCounter UI API

Read recent pickup and location-discovery records as JSON snapshots from native plugins through a read-only C ABI.

What the API exposes

The version 1 header provides a dynamic C ABI for read-only snapshots. It does not expose internal C++ types, renderer control, PrismaUI views, or game-thread event sinks. If SkyCounter UI is absent, your mod should continue without this optional integration.

  • Recent pickup records retained by the module (up to its current stream limit).
  • Recent location discovery/capture records retained by the module.
  • UTF-8 JSON copied into caller-owned buffers.

Snapshot indices are not persistent IDs. Re-read the count and fetch again after the stream changes. Treat JSON as extensible: ignore unknown properties.

Connect once during plugin initialization

#include <windows.h>
#include "SkyCounterUIAPI.h"

SkyCounterUIAPI g_counter{};

bool ConnectSkyCounterUI()
{
    const HMODULE module = GetModuleHandleW(L"SkyCounterUI.dll");
    return SkyCounterUI_LoadAPI(module, &g_counter) != 0;
}

The game must have loaded SkyCounter UI before the lookup. Resolve the API when your plugin initializes after SKSE loads plugins. Keep your feature optional if the module is not installed.

Copy one JSON record

std::string ReadPickup(uint32_t index)
{
    const uint32_t needed = g_counter.copyRecentPickupJsonAt(index, nullptr, 0);
    if (!needed || needed > 65536) return {};
    std::string json(needed, '\0');
    if (g_counter.copyRecentPickupJsonAt(index, json.data(), needed) != needed) return {};
    json.resize(needed - 1); // exclude terminating NUL
    return json;
}

void ReadRecentPickups()
{
    if (!g_counter.getRecentPickupCount) return;
    const uint32_t count = g_counter.getRecentPickupCount();
    for (uint32_t i = 0; i < count; ++i) {
        const auto json = ReadPickup(i);
        if (json.empty()) continue;
        // Parse as UTF-8 JSON with your preferred JSON library.
    }
}

The copy functions return required capacity including the NUL terminator. Pass a null buffer and zero capacity for the size query, allocate that many bytes, then call again. A zero return means the index is no longer present or is invalid. The same pattern applies to copyRecentLocationJsonAt.

Pickup record shape

{
  "item": {
    "plugin": "Skyrim.esm",
    "name": "Iron Sword",
    "category": "Item",
    "formID": "00012EB7",
    "localFormID": "00012EB7",
    "lastPickup": 1,
    "discoveredNow": false,
    "icon": "file:///..."
  }
}

Location record shape

{
  "key": "Skyrim.esm|0001A2B3",
  "plugin": "Skyrim.esm",
  "name": "Whiterun",
  "formID": "0001A2B3",
  "localFormID": "0001A2B3",
  "discoveredNow": true,
  "image": "file:///..."
}

Form IDs are hexadecimal strings. Icon/image URLs can be empty when no capture exists. Snapshot accessors copy records under the module's history locks. They do not require access to Skyrim forms and can be called from a worker thread, but callers must synchronize their own parsing/UI work and handle a changing snapshot.

Mod ideas

  • Native pickup journal: show a searchable list of recent pickups in a mod-owned native window.
  • Collection companion: display new pickup/location captures alongside your own progression checklist.
  • Accessibility feed: convert recent record data into a mod-owned speech or high-contrast notice.
  • House catalog: pair discovered-location records with a mod's own custom map and location notes.
  • Optional web companion: let your native plugin transfer copied data to your own UI. Keep all game actions in your plugin and validate input.

This API does not promise a continuous callback, full lifetime history, or renderer access. Use your own supported SKSE event listener if your feature needs immediate event timing or gameplay changes.

Packaging and troubleshooting

  1. The SkyCounter UI project package includes this header and guide with the app runtime.
  2. At runtime, SkyOS Core and SkyCounter UI must be enabled in the user's profile. Mods that use the API should treat it as optional.
  3. To create a 7-Zip archive from this project, configure and build its Release preset, then run cpack --config build/CPackConfig.cmake -G 7Z -C Release.
  • API lookup fails: verify SkyCounterUI.dll has loaded and that the version 1 exports are present.
  • Count is zero: there may be no retained event records yet; zero is not an error.
  • Copy returns zero: re-read count and index because the current stream may have changed.
  • JSON fields change: ignore unknown keys and avoid assuming snapshot indices are stable.
